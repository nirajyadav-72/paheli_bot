# paheli_bot
# 🎯 Telegram Paheli Game Bot

यह एक टेलीग्राम ग्रुप पहेली गेम बॉट है।

## 🚀 फीचर्स
- ग्रुप में ऐड होते ही वेलकम मैसेज।
- स्मार्ट आंसर मैचिंग (हिंदी + इंग्लिश दोनों में)।
- लाइव स्कोरबोर्ड/लीडरबोर्ड।

## 🛠️ सेटअप कैसे करें
1. प्रोजेक्ट डाउनलोड करें।
2. `.env` फाइल बनाकर `BOT_TOKEN` और `OWNER_ID` डालें।
3. `pip install -r requirements.txt` रन करें।
4. `python main.py` से बॉट चालू करें।
